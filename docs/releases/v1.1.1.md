## GPRadar-API 1.1.1 (2026-11-19)

- The three bundled samples have clearer display names: "Utility (Mendeley)", "Void (Mendeley)" and "400 MHz (gprMax)".
- README: link to the live demo at https://gpradar.hectorvh.com, a production `ALLOWED_ORIGINS` (CORS) example, and a note that the web UI's About dialog links to this repository.
- `/health` now reports `api_version` 1.1.1.
- No change for clients: the endpoints, request fields and response contract are the same as in 1.1.0, and sample ids are unchanged.
- Render deploys `main` automatically, so the live service updates once this release is merged.
